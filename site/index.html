01 / The idea

Not another window.
A change of scenery.

Mountains on the horizon. A long neck in the treetops. Something small stirring by the lake. Omarchasaurus turns a character grid into a place worth pausing for.

Open Enter Immersion from the tray to explore on your focused output. Or choose Start All Outputs for a screensaver-style valley on each display. Both are started manually.

Read the project notes ↗
I.

A little curiosity
goes a long way.

In immersion, click a dinosaur for a head, jaw or tail reaction. Click open sky for a meteor; lake water for a leap and splash. One meteor and one lake leap can coexist, with a free animal slot needed for the leap.

II.

Your kind
of quiet.

Morning or Dusk changes the palette, not the world’s behavior. Set reduced motion independently. Tune scenery, optional animals and crowding without tying them to a color scheme.

III.

A new arrangement.
On your terms.

Randomize Valley stages a fresh mix of scenery and optional residents. Review it, then Apply. It never silently rerolls your scene or saves those choices automatically.

04 / Bring it home

A valley.
One command away.

For Omarchy Quattro, its Quickshell-based shell, and Hyprland. You’ll also need Python 3.11+, Ghostty or Kitty, and a UTF-8 truecolor terminal with a monospace font.

Dependencies must already be installed. No runtime package installer, account, API key or elevated helper.

01

Add the plugin

Your terminal
omarchy plugin add https://github.com/DailenG/Omarchasaurus --enable

Select the command to copy it manually.

02

Find your new tray neighbor

Open the Omarchasaurus tray menu, then choose Enter Immersion. Choose Start All Outputs for screensaver-style sessions; Surface stops only its owned sessions.

05 / Before you wander

A few
field notes.

The complete README ↗
Is this a game I can play in my browser?

No. This website shows static captures from the actual production canvas. The interactive valley runs in a real terminal as an Omarchy Quattro plugin. The Morning / Dusk viewer here demonstrates the two palettes, not live animation.

Will it run on my desktop?

The supported setup is Omarchy Quattro with its Quickshell shell and Hyprland, Python 3.11 or newer, and Ghostty or Kitty. It is not presented as a general Windows, macOS or other Linux desktop app.

Is it an automatic screensaver?

Not yet. In this development preview, you manually choose Enter Immersion or Start All Outputs from the tray. Automatic idle activation and sound are off and not implemented. Ordinary input dismisses screensaver-style Start sessions; immersion is the interactive mode.

Does it connect to anything?

The plugin runtime makes no HTTP/TCP requests. Installation and updates through Omarchy contact GitHub. Runtime integration is local: Hyprland, Omarchy/Quickshell IPC and same-user Unix sockets. This website uses no analytics, cookies or browser storage. Community plugins are unsandboxed user code; this is not a security certification. Read the full security notes.

Can I make it quieter?

Yes. Reduced motion is an independent setting. Choose optional animals, adjust scenery density and set an animal ceiling. Morning and Dusk only change colors. Randomize stages choices for review, rather than saving automatically.

How do I update or remove it?

Surface owned sessions and apply or discard staged settings before updating. Use Omarchy’s normal plugin updater; the README includes the one-time 0.1.0 migration and source-checkout caveats. Removal keeps your saved settings intentionally. Follow the update instructions or removal instructions for the complete steps.
